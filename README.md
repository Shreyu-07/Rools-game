## **Rools-games**

## Rules

1. Roll two six-sided dice.
2. If the sum of the dice is even, you win!
3. If the sum is odd, you lose.

## Requirements

- Python 3.x
- `pyttsx3` library for text-to-speech

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/shreyu-07/lucky-burst.git
   ```
2. Navigate to the project directory:
   ```bash
   cd lucky-burst
   ```
3. Install the required packages:
   ```bash
   pip install pyttsx3
   ```

## How to Play

Run the game:
```bash
python lucky_burst.py
```

Follow the on-screen instructions to play!
